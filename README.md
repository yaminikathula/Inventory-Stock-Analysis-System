StockWise – Inventory and Stock Analysis System

Project Overview

StockWise is a web-based inventory management and stock analysis system developed using Python, Flask and MySQL.

Features

- Product and supplier management
- Stock IN and Stock OUT
- Current stock calculation
- Low-stock alerts
- Fast-moving and slow-moving product analysis
- Inventory valuation
- Stock adjustments and audit logging
- Stock movement charts

Technologies Used

- Python
- Flask
- MySQL
- Pandas
- NumPy
- Matplotlib
- HTML
- CSS

Objective

To manage inventory efficiently, track stock movements and identify low-stock products.

Expected Outputs

- Current stock report
- Low-stock list
- Stock movement chart
- Estimated inventory value
